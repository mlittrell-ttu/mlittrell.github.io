# Teacher Apps

Small, friendly apps for the classroom. Each app is a single HTML file that works offline, needs no account, shows no ads and never sends data anywhere. Open one in a browser, or download the file and keep it.

## How the files are built

- Everything an app needs (HTML, CSS, JavaScript) is inside its one file. No outside fonts, scripts or images.
- All apps share the Teacher Apps look: a cool white background, slate text, system fonts and rounded cards.
- Each app has its own colour, used for the thin stripe at the top, its icon and its main buttons:
  Timer blue, Flashcards green, Percentages purple, Center and Spread amber, Noun Match coral, Well-Being teal.
- The logo in each app's header links back to the home page.

`about.html` and `downloads.html` now redirect to sections of the home page so old links still work.
